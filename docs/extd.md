# EXTD 残留日文与 DC 日版的对齐口径

美版每条对白记录带一个 `EXTD` 段，装载日文原文。任务是把这些日文与 DC 日版的主文本逐条对上，得到"剧本是否同源"的量化结论。

难点不在读取，而在**怎么对齐**。同一批数据用三种口径会得到 51%、72%、94% 三个结果，差别全部来自对齐方式，而非文本本身。

## 1. 三种口径

| 口径 | 台词命中率 | 失真来源 |
|---|---|---|
| 按记录序号对齐 | 71.68% | 两平台记录条数／顺序不同，产生整体位移 |
| 内容对齐（不判语种、不分层、不去重） | 51.44% | 英文 `EXTD` 与短名条目被算成 miss；同名文件重复计数 |
| 内容对齐 + 语种判定 + 分层 + 去重 | **94.03%**（主线 99.84%） | 采用 |

### 1.1 序号对齐为什么会错

`0102.afs` 里出现连续一位偏移：

```
DC: ２   ３   ４   ５   ６   ７   ８
XB: ３   ４   ５   ６   ７   ８   ９
```

`0015.afs` 则是整段位移：DC 第 2 条 `また、おまえか…` 在美版对应的是另一句。若按序号比较，这些都会被记成"文本改动"，但实际只是记录顺序不同。

因此最终口径放弃序号，改为：**Xbox 的 EXTD 文本是否出现在同 AFS 的 DC 记录集合中**。

匹配优先级：

1. `(speaker, 文本)` 同时命中（最严）
2. 仅文本命中（speaker 名在两版间有别名）
3. 都不命中 → miss

## 2. 语种判定

`EXTD` 不总是日文。`0120.afs` 里就有：

```
Uh=@well=@
Okay.＆Goodbye.
Southeast?
Save?＆Where?
```

这些是英文段落（`=@` 为控制码），若计入日文统计会拉低命中率。判定在字节层完成，不依赖解码：

```python
def is_japanese(b):
    i = 0
    while i < len(b):
        c = b[i]
        if c < 0x80:
            i += 1
            continue
        if i + 1 >= len(b):
            return False
        c2 = b[i + 1]
        if 0xA4 <= c <= 0xA5 and 0xA1 <= c2 <= 0xF6:
            return True          # 平假名 / 片假名
        if 0xB0 <= c <= 0xFE and 0xA1 <= c2 <= 0xFE:
            return True          # 汉字
        i += 2
    return False
```

本次全量：非日文 `EXTD` 共 2,459 条，全部排除在主结论之外。

## 3. 归一化

只处理尾部填充，避免"只差空白"被判为不同：

```python
b = b.rstrip(b"\x00\x20")
while b.endswith(b"\xa1\xa1"):        # 全角空格
    b = b[:-2].rstrip(b"\x00\x20")
```

不做任何符号替换——因为两平台的符号字节本来就一致（见 [`symbols.md`](symbols.md)），替换会掩盖真实差异。

## 4. 分层

| 层 | 阈值 | 性质 |
|---|---|---|
| 台词级 | ≥ 10 B（5 个双字节字符以上） | 主结论口径 |
| 短条 | < 10 B | 人名、名牌、单词应答 |

短条的样本（`data/short_samples_FREE01.tsv`）：

```
えっ？ / そうか… / ああ… / 失せな！ / 消えな！ / ジョーンズ / "涼
```

这类条目的命中率只有 5.55%，但**不能据此说"文本不一致"**：DC 侧的人名与名牌多存在 HUMANS／名片一类结构里，不在 STREAM 主文本。短条需要单独与那些表交叉验证，本仓库暂未做。

## 5. 结果

| 分组 | 文件数 | 台词 | 命中 | 率 |
|---|---|---|---|---|
| 主线／过场 | 334 | 12,840 | 12,819 | **99.84%** |
| FREE01–04 | 4 | 30,237 | 27,774 | 91.85% |
| `0137.afs` | 1 | 64 | 0 | 0.00% |
| `S2BV.afs` | 1 | 27 | 0 | 0.00% |

- **主线／过场 99.84%**：剧本同源成立，这是核心结论。
- FREE 系列是自由对话／随机闲聊池，两平台收录量与编排不同（DC 记录 98,913 vs 美版日文台词 43,168），其差异应理解为版本内容差异。
- `0137`／`S2BV` 是独立表（人名、影像相关），不参与剧本判断。

## 6. 样本

`0005.afs` / `RYO_STDL` / 第 0 条，两侧 20 字节完全相同：

```
A5 EF A5 F3 A5 C1 A5 E3 A5 A4  → ワンチャイ
A1 C4                          → …
B9 C8 C6 EE B3 B9              → 紅南街
A1 C4                          → …
A1 F5                          → 换行
B2 B8 C5 C4 CF B0              → 恩田楼
A1 C4                          → …
```

实机显示为两行 `ワンチャイ…紅南街…` / `恩田楼…`。

DC 侧偏移 897,056 附近；美版侧偏移 882,780 附近，位于 `EXTD` 子段内。

## 7. 未命中的使用

`data/extd_miss_long.csv` 记录了 2,575 条台词级未命中，字段包括 `file / block / record / speaker / len / text / hex`。

按文件排序可以看到差异高度集中：FREE03 1,457、FREE02 664、FREE01 341，其余文件多为个位数。定位具体句子时，直接按 `file + block + record` 回读即可。

另有两个值得注意的个案：

- `0032.afs`：`１度も` 与 `一度も`（全角数字与汉字数词的写法差异），属版本级改写而非翻译。
- `0120.afs`：英文 `EXTD` 与短名混排，说明该文件的 `EXTD` 用途与对白文件不同。

## 8. 与旧记录的关系

早期工程曾给出"4,541 / 4,547 = 99.9%"。该数字口径不明（覆盖范围、是否排除短条与英文段均未记录），本仓库不以它为依据。本次是 340 个 AFS、43,168 条日文台词的全量统计，主线组 99.84% 与该旧值同量级，但**分母、判定与文件范围都可复现**。
